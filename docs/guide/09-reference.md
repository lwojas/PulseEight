# Reference

## Limits

| | |
|---|---|
| Tracks | 8 (6 drums, ACID and FM) |
| Patterns | 64 |
| Steps per pattern | 16, 32, 48 or 64 |
| Chain length | Up to 64 entries |
| Tempo | 60 – 200 BPM |
| Swing | 50 – 75% |
| Notes playing at once | 32, shared across all tracks |
| Punch FX | 9 |
| Project name | 40 characters |

## Factory sounds

**Drum kits:** 909 CLASSIC, 808 BOOM, TECHNO HARD, DUB DRY.
**ACID:** ACID 303, SQUELCH, SQUARE, PUNCH, SUB PUSH.
**FM:** FM BASS, HOLLOW LEAD, BELL PLUCK, METAL STAB, SUB GROWL.

## Scales

Chromatic, Major, Minor, Dorian, Phrygian, Lydian, Mixolydian, Locrian, Harmonic Minor, Melodic Minor, Pentatonic Major,
Pentatonic Minor, Blues, Whole Tone.

## Note names

Note names follow the convention that **MIDI note 24 is C1**. ACID plays C1 – B3; FM plays C2 – B4.

## Arpeggiator rates

`1/4`, `1/8`, `1/8T`, `1/16`, `1/16T`, `1/32`.

## Delay times

`1/16`, `1/8`, `1/8.` (dotted eighth), `1/4`, `1/8T` (eighth-note triplet). Used by the track delay in SYNC mode and by
the DUB pad.

## Hit strength

A normal step plays at 70%. An accented step plays at 100%.

## Shortcuts

| Key | What it does |
|---|---|
| `Space` | Play / stop |
| `1` – `8` | Select a track and hear it |
| `[` `]` | Previous / next page |

## Touch and mouse actions

| Action | Where | What it does |
|---|---|---|
| Tap | Drum pad | Switch the hit on or off |
| Hold, or Shift-click | Drum pad | Select the step (then use ACCENT) |
| Tap | Empty melodic step | Add a note and select it |
| Tap | Selected melodic step | Remove the note |
| Hold | Melodic step | Add and select it |
| Shift-click | Any step | Select it without changing it |
| Double-tap | Knob, slider | Reset to its starting value |
| Drag | Knob, slider | Change the value |
| Two taps | CLR TRACK, CLR PTN, … | Confirm a clear |
| Hold | Punch pad | Fade the effect in; let go to fade out |
| Hold | ERASE | Clear all FX lanes as they play |

## Short labels on phones

On a narrow screen, the clear buttons (CLR STEP, CLR TRACK, CLR PTN, CLR CHAIN, CLR FX, CLR LANE) all read **CLR**, and
ACCENT / SLIDE read **ACC** / **SLD**. They do the same thing as on a larger screen.

## Troubleshooting

**No sound.** Tap START: browsers won't play audio until you've tapped something. If the start screen shows an error,
your browser couldn't start its audio. Try an up-to-date Chrome, Edge, Firefox or Safari.

**The timing sounds uneven on a phone.** Close other tabs and apps, and keep the screen on. Pulse.8 keeps its own steady
time, so uneven timing almost always means the phone is busy with something else.

**My work didn't survive a reload.** If your browser is blocking saving (for example in a private window), the SAVE button
shows a warning. Use **EXPORT** to keep your work as a file.

**MIDI does nothing.** Check that **MIDI: ON** is set, that you gave the browser permission, and that your controller is
sending on the channel of the track you mean (track 3 is channel 3).
