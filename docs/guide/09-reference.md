# Reference

## Limits

| | |
|---|---|
| Tracks | 8 (6 drums, ACID, FM) |
| Patterns | 64 |
| Steps per pattern | 16, 32, 48 or 64 |
| Chain length | up to 64 entries |
| Tempo | 60 – 200 BPM |
| Swing | 50 – 75% |
| Polyphony | 32 voices shared |
| Punch FX | 9 |
| Project name | 40 characters |

## Factory sounds

**Drum kits:** 909 CLASSIC, 808 BOOM, TECHNO HARD, DUB DRY.
**ACID:** ACID 303, SQUELCH, SQUARE, PUNCH, SUB PUSH.
**FM:** FM BASS, HOLLOW LEAD, BELL PLUCK, METAL STAB, SUB GROWL.

## Scales

Chromatic, Major, Minor, Dorian, Phrygian, Lydian, Mixolydian, Locrian, Harmonic Minor, Melodic Minor, Pentatonic Major,
Pentatonic Minor, Blues, Whole Tone.

## Notes

Note names follow the convention **MIDI 24 = C1**. ACID plays C1 – B3; FM plays C2 – B4.

## Arpeggiator rates

`1/4`, `1/8`, `1/8T`, `1/16`, `1/16T`, `1/32`.

## Delay divisions

`1/16`, `1/8`, `1/8.` (dotted eighth), `1/4`, `1/8T` (eighth-note triplet). Used by the track delay in BEAT mode and by
the DUB pad.

## Velocity

Normal step: 70%. Accented step: 100%.

## Troubleshooting

**No sound.** Tap START; browsers will not play audio before a gesture. If the start screen shows an error, the browser
could not start its audio engine: try a current Chrome, Edge, Firefox or Safari.

**Timing is uneven on a phone.** Close other tabs and apps; keep the screen on. The scheduler runs on its own timer and
the playhead never goes through the UI, so uneven timing is almost always the device being busy.

**My work did not survive a reload.** The SAVE button will show a warning if the browser is blocking storage (private
window, site data disabled). Use **EXPORT**.

**MIDI does nothing.** Check **MIDI: ON**, that the browser granted permission, and that the controller is on the
channel of the track you mean (track 3 is channel 3).
